# The House Protocol


This is a self hosted market risk and geopolitical monitoring system. 
It ingests the market, macro and geopolitical data, scores risk, and sends a Discord alert.

This is an early warning and situational awareness tool. It does not predict prices or produce trade signals.


## Quick start up

1. Copy `.env.example` to `.env` and fill in the values
2. Run `docker compose up -d --build`
